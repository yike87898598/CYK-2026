# CYK 个人站 2026

这是可直接发布到 GitHub Pages 的静态网站。`index.html`、其他案例页面与 `assets/` 必须一起放在仓库根目录；无需安装依赖或运行构建命令。

## 上传与发布

1. 用 GitHub Desktop 将本文件夹创建为本地仓库，并发布到 GitHub。请勿仅用 GitHub 网页拖拽上传：部分 PDF、视频超过网页端 25 MiB 的单文件限制。
2. 在仓库的 **Settings → Pages** 中选择 **Deploy from a branch**，设置为 `main` 分支、`/ (root)`，然后保存。
3. 等待 Pages 显示网址后，检查首页、六个案例页、视频及 PDF 下载。

上线前请确认页面中的联系方式和可下载 PDF 均可公开。这里保留了网站实际使用的素材与文件，未包含设计过程中的原始工作文件。

参考：[GitHub Pages 发布说明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)、[GitHub 文件上传限制](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github)。
